I built a Streamlit app (`payroll_app.py`) that processes uploaded timesheet files for Salt City Coffee and remembers results across uploads. The core challenge was that Streamlit re-runs the whole script on every interaction, so anything I wanted to accumulate, like a running count of files and employees paid, would reset unless I handled it deliberately. The most valuable pattern I learned was guarding logic behind `if` statements. Wrapping processing in `if timesheet_file is not None:` prevents an `AttributeError`, since `st.file_uploader` returns `None` until a file is chosen. Pairing that with a button (`if process and session_state.timesheet is not None:`) separates choosing a file from processing it, so the work runs only once per click and the same file isn't double-counted.

I paired that with the three-part session-state pattern: initialise values once with `if "files_processed" not in st.session_state:`, update the totals inside the guarded block, and display from state using `st.metric` cards in `st.columns(2)` plus an `st.info` line per file from `st.session_state.file_summaries`. On the data side, I kept the **grain** in mind (one row per employee per shift) so merges and totals didn't duplicate or collapse rows. A **left merge** of timesheets onto the pay-rate table kept every shift and surfaced any unmatched employee as **NaN**, which kept the **lineage** of each pay figure traceable. I used `pd.to_numeric(..., errors="coerce")` so malformed hours became NaN instead of crashing, then a **boolean index** to isolate and flag those rows.

For calculations, I wrote an **element function** that computes pay for a single value and ran it down a column with **`Series.apply`**, using **`axis=1`** when a calculation needed several columns in the same row. My helpers follow a **copy-add-return** style, so the uploaded data is never mutated and reruns stay predictable. Going forward, I want to rebuild the session-state pattern on a different app from memory, handle the edge cases I noticed (`os.makedirs("data", exist_ok=True)` and `timesheet_file.seek(0)` before re-reading), and match public-facing text like titles and success messages to the spec before running the tests.
